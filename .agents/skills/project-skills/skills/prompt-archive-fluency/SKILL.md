# prompt-archive-fluency

**When to apply:** When the user wants to search past prompts or generate a fluency report.

**First-use Initialization:**
If not initialized, prompt the user to run `python scripts/workflow.py init`.

**Shared CLI Commands:**
- `python scripts/workflow.py prompts --keyword <keyword>`
- `python scripts/workflow.py fluency-report`
- `python scripts/workflow.py export --out <file>`

**Usage:**
- Never modify the original usage.jsonl.
- Fluency report is fact-based and respectful.
